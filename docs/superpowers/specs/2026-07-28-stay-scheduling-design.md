# 住宿排期设计

## 目标

让每日住宿支持多个候选酒店，并将当前住宿以可调整的入住排期显示在时间轴中。

## 数据与规则

- `Day.stays` 保留所有候选住宿；每个 Day 至多一项 `isPrimary: true`。
- 新增 `StaySchedule`，引用 `stayId`，并保存 `dayId`、`startSlot`、`durationSlots`、`isTimeLocked`。
- 仅当前住宿允许从右侧住宿区拖入时间轴；拖入默认持续 30 分钟。
- 切换当前住宿时，若旧主住宿在当天已有排期，新主住宿继承原排期的时间、时长和锁定状态；否则只切换当前住宿。
- 住宿排期复用时间轴的移动、缩放、删除和冲突顺延规则。

## 界面

- 今日住宿按卡片列出全部候选；每张卡可编辑、删除或设为当前住宿。
- 当前住宿卡显示状态标记和拖拽手柄；非当前卡显示“设为当前住宿”。
- 时间轴中的入住卡与活动卡视觉区分，点击打开对应住宿详情。

## 边界

- 删除主住宿时同时删除其排期，并将其余第一张住宿设为主住宿。
- 预算与地图继续读取 Day 的住宿数据，不改变现有计算口径。
