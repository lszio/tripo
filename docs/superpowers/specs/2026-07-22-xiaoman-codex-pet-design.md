# 小满 Codex 桌宠设计

## 目标

为 Codex 安装一个名为“小满”的独立 v2 动画宠物。它不修改 Codex 内置资源，可在后续安全地替换或优化。

## 视觉身份

- 风格：可爱写实，保留真实毛发质感。
- 特征：银白底色、深棕豹纹、冰蓝眼睛、粉色鼻头、大耳朵与深色肉垫。
- 姿态：身形修长、好奇亲人；“抬头看人”和“伸爪”是主要性格动作。

## 动画范围

生成 Codex v2 所需的 11 行精灵图：待机、向右走、向左走、招手、跳跃、失败、等待、工作、审阅，以及 16 个连续的视线方向。每帧使用透明背景，按 Codex 的 192x208 单元尺寸打包。

## 安装与可优化性

- 安装到 `/Users/ruhua/.codex/pets/xiaoman/`，包含 `pet.json` 与 `spritesheet.webp`。
- `pet.json` 使用 `spriteVersionNumber: 2`，让 Codex 识别完整方向动画。
- 后续优化以单行动画或完整精灵图替换为单位；保留 `id`、清单格式与已通过的行即可。

## 验收

- 精灵图尺寸为 1536x2288，背景透明，v2 验证通过。
- 全部动作保持小满的花纹、眼睛、脸型与比例一致。
- 走路动作方向正确且步伐连续；待机有轻微动态。
- 四个基准视线方向清晰，16 个方向连续自然。
