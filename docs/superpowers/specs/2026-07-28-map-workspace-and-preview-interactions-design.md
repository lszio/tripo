# 地图工作区与预览交互设计

## 目标

将路书编辑器中的地图从右侧小组件扩展为独立地图工作区，并修复地图与编辑抽屉的层级冲突，同时改善地点文本、封面图片和卡片预览的关闭方式。

## 地图工作区

- 右侧保留放大的当日地图预览，并提供“进入地图工作区”入口。
- 地图工作区是应用内独立视图，不使用浮窗；进入后保留旅行与当前 Day 上下文。
- 专有页面包含顶部返回操作、当前 Day 切换、当天节点列表和占主要空间的交互地图。
- 返回编辑器时保留当前 Day 和活动预览状态。
- 结构预留节点筛选、路线编辑、地图选点等后续交互的位置，但本轮不实现这些能力。

## 地图稳定性与层级

- 编辑抽屉、确认框和通知的层级高于 Leaflet 所有 pane；地图不再穿透编辑界面。
- 地图使用公开 OSM 标准瓦片 URL，显式保留跨域 Referer，并为加载错误提供无色回退，避免异常图块遮挡内容。
- 地图预览和地图工作区均保留 OSM 署名。

## 编辑与预览

- 已选地点以紧凑标签呈现，地点名最多显示两行并允许换行；点击“更换地点”后才显示搜索输入与候选列表。
- 活动图片在卡片与详情图中采用固定比例的居中封面裁切，不拉伸、不重复。
- 点击素材卡或时间轴卡仍可打开活动预览；点击工作区的非交互空白区域关闭预览。

## 验证

- 抽屉打开时地图控制和标记不会越过抽屉。
- 可以进入、返回地图工作区，并保留所选日期。
- 长地点名称不会撑宽抽屉。
- 点击空白时间轴关闭预览，点击卡片或预览内容不关闭。
