# 地点选择器与卡片图片展示设计

## 目标

将活动与住宿的手动地点输入改为可搜索、可选择的地点流程，并确保用户上传的图片在所有卡片中以等比裁切方式展示。

## 地点选择器

- 活动详情与住宿详情共用 `LocationPicker` 组件。
- 用户输入关键词后，点击搜索按钮或按 Enter 才发起地点查询；不在每个键入事件中自动请求。
- 查询结果以列表形式展示；选择一项后，将显示名称、纬度和经度写入草稿。
- 详情抽屉不再公开纬度与经度的手动输入控件；已选择的位置显示为可清除的地点标签。
- 结果按关键词缓存；两次网络查询之间至少间隔一秒。
- 网络失败或无结果时，在控件附近显示可理解的提示，且不丢失用户输入。
- 搜索服务使用 OSM 的 Nominatim 端点，并在界面中保留 OpenStreetMap 查看链接及服务署名。

## 图片展示

- 活动图片保持原有 `image` 字段和上传、URL 两种录入方式。
- 素材库、时间轴卡片、活动预览及图片预览都采用居中、等比、裁切覆盖的策略：`background-size: cover`、`background-position: center` 与 `background-repeat: no-repeat`。
- 图片仅作为视觉背景；标题和关键信息通过稳定的深色渐变层保持可读性。

## 验证

- 活动和住宿均可搜索地点、选择结果、保存并在地图预览中出现标记。
- 搜索无结果或网络失败时控件可继续编辑。
- 不同横竖比例图片不会拉伸或重复。
